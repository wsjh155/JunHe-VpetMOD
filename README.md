给你的桌宠一张「房号」：和朋友装了这个 mod 的桌宠互相投喂、发红包、摸头打招呼，  
再通过「桌宠云桥」把房间、排行榜和整份存档搬到云端，手机也能看。

- 作者：君赫
- 版本：2.1.0
- 适用：VPet（Steam 版），游戏版本 11075 及以上

## 功能一览

| 功能    | 说明                                      | 需要联网     |
| ----- | --------------------------------------- | -------- |
| 访客表联机 | 基于 Steam P2P 大厅，**不需要自建服务器**，也不用手动填 IP  | 只需 Steam |
| 桌宠好友  | 把常联机的玩家存成好友，下次一键找到                      | 只需 Steam |
| 快捷互动  | 打招呼、发红包、摸头/摸身/捏脸，对方桌宠会实时反应              | 只需 Steam |
| 批量投喂  | 选食物、选数量（x1/x5/x10/x50），一次投喂给好友，还能先看食物属性 | 只需 Steam |
| 云端房间  | 开着访客表会自动登记到云端，别人在网页或 mod 里都能看到并加入       | 需要云桥     |
| 排行榜   | 等级榜（按等级 → 转生次数 → 金钱排序）与金钱榜              | 需要云桥     |
| 云存档   | 上传/恢复**整份 `.lps` 存档**（等级、转生、金钱、背包全在里面）  | 需要云桥     |
| 手机访问  | 网页自适应，手机上可看房间、排行榜、存档列表                  | 需要云桥     |

> 转生 = 桌宠突破等级上限的次数，等级榜会把它作为第二排序依据，所以转生过的玩家不会被低等级反超。

## 安装

**创意工坊**：订阅后在游戏内启用即可。

**手动安装**：把整个 `1145141_OnlineInteraction` 文件夹放进

```
VPet/mod/1145141_OnlineInteraction/
├─ info.lps
├─ icon.png
└─ plugin/
   └─ VPet.Plugin.OnlineInteraction.dll
```

目录名前面的数字只是加载顺序，不要改名成别的数字组合，否则可能和其他 mod 冲突。

**卸载**：删掉上面这个文件夹即可。存档不会受影响，云端数据保留在云桥上。

## 使用教程

### 第一步：打开访客表

右键桌宠 → **互动** → **访客表**。

访客表窗口打开后，左侧会多出本 mod 的三个页签：

- **互动** —— 好友列表 + 快捷操作 + 批量投喂（内含 互动 / 桌宠好友 / Steam好友 / 联机历史 四个子页）
- **联机大厅** —— 我的房间（固定 ID）、合并的房间列表（标 [P2P] / [云]）、等级榜 + 金钱榜、按固定 ID 加入
- **管理** —— 只有作者或被授权的管理员才看得到

### 第二步：和朋友连上

两种方式，任选：

**A. 自己开房（当房主）**

1. 在访客表窗口点「**创建**」，你就成了房主。窗口左上角会显示两个号：
   - `ID: 18600008f49b79a` —— Steam 内部大厅号，一长串，不用管
   - `固定 ID: V255082` —— **这个才是你要发给朋友的**，游戏官方分配，好记
2. 把固定 ID（`V255082`）发给朋友，或者让朋友在「联机大厅」页点「**刷新大厅**」自己找。
3. 房主关掉访客表，房间就散了。

**B. 加入别人的房**

- 在「联机大厅」页的房间列表里点「加入」；或
- 在下方「按固定ID加入」输入框里填对方的**固定 ID**（`V255082` 或直接 `255082`），点「加入」——
  mod 会走游戏自带的解析接口把这个短号换成大厅号再进房，和游戏内「加入访客表」完全一样。

加入成功后，对方的桌宠会出现在你的「桌宠好友」列表里。

### 第三步：互动

在「互动」页选中一个好友，然后：

- 输入一句话点「**打招呼**」——对方会看到气泡和消息日志
- 填金额点「**发红包**」——直接给对方加金币
- 点「**摸头 / 摸身 / 捏脸**」——对方的桌宠会做出对应动作并提示「XXX 摸了摸你的头」
- 「**批量投喂**」：选食物 → 选数量 → 点「投喂」，食物属性（Exp / 饱腹 / 心情 / 好感等）会显示在选择框下方

这些都走 Steam P2P，**不经过任何第三方服务器**，也不需要双方同时在线以外的条件。

### 第四步：打开云桥（可选，云端功能才需要）

在「联机大厅」页点「**打开云桥网页**」，会弹出浏览器窗口。

首次使用要登录：**微信扫码**为主（手机上确认即可），也可以改用 **WorkBuddy 登录**。

登录后网页上有四块内容：

1. **本机桌宠** —— 显示是否连上本机 VPet、当前等级/转生/金钱/存档、是否正在开放访客表
2. **云端访客表** —— 你开着的访客表会自动登记；点「加入」经 Steam 进入（需要本机 VPet 在线）
3. **云存档** —— 左边是本机存档列表，右边是云端存档；上传的是**整份 `.lps` 文件本体**
4. **排行榜** —— 等级榜 / 金钱榜，数据来自所有登录并开着 VPet 的玩家

> 网页地址（可收藏，手机直接打开）：  
> `https://vpet-cloud-bridge.app.workbuddy.host/?sharecode=PKDQBM3ZNG`
>
> 注意：链接必须带 `?sharecode=` 这一串，否则会提示「链接不完整」。

### 第五步：云存档怎么用

**上传**：网页「云存档」区 → 左边选一个本机存档 → 点「上传所选存档到云端」。

**恢复**：右边云端列表点「恢复」。恢复是**原地还原**，不需要重启游戏，而且会**自动先备份当前存档**（备份文件保留在 Saves 目录里）。

因为传的是整份存档，等级、转生次数、金钱、背包物品、当前状态会一起回来。

### 手机上能做什么

手机浏览器打开上面的链接即可：

- 能看：云端访客表、排行榜、云端存档列表
- 不能做：上传/恢复存档、加入房间——这些必须在本机连着 VPet 的电脑上操作

## 常见问题

**点「创建」提示「已经有加入了一个访客表，无法再创建更多」，但看不到窗口**  
访客表窗口的实例卡住了。到「联机大厅」页点「**重置访客表**」——它会强制退出当前大厅、关掉窗口、清空游戏里的窗口引用，然后就能重新创建了。

「联机大厅」页右上角会实时显示访客表状态，正常情况下是「访客表: 已打开」或「未打开」，如果显示「实例还在但窗口不可见」，就是该重置了。

**点「打开云桥网页」没反应**  
窗口不是瞬间弹出的：mod 要先清掉后台那个隐藏的云桥浏览器、等它释放配置目录，再开可见窗口，大概 **1 秒**后才出现。稍等一下。

如果超过 3 秒还是没有，看日志：

```
C:\Users\君赫\AppData\Local\VPet\cloudbridge.log
```

日志会明确写出是「配置目录仍被占用」还是「可见窗口未出现」，以及是否降级用系统默认浏览器打开了页面。

**网页上「本机桌宠」一直显示未连接**  
说明网页没连上本机的 mod。依次检查：

1. VPet 是否正在运行（mod 只在游戏运行时才有本地服务）
2. 是否用的 `127.0.0.1:27551` 对应的那台电脑（手机端本来就连不上本机，显示未连接是正常的）
3. **浏览器是否放行了「本地网络访问」**：新版 Edge/Chrome 默认不允许公网 https 页面访问 `127.0.0.1`。在地址栏左侧站点图标里把「本地网络访问 / 回环网络」改成允许，或到 `edge://settings/content` 里给网站加白名单，然后点「重新检测」
4. 关掉网页重新点一次「打开云桥网页」，让它用受管浏览器重新加载

**云端房间和排行榜是空的**  
云端房间、排行榜的数据要靠云桥网页推送过来。先确认已在网页上登录、并且本机桌宠显示「已连接」；然后回到 mod 点「**刷新云端**」。

**排行榜里没有我**  
登录云桥、并且 VPet 开着，就会自动上榜。等级榜按「等级 → 转生次数 → 金钱」排序，同等级时转生多的排前面。

**微信登录提示未开启**  
云端控制台里微信登录开关没打开时会这样，可以先用「WorkBuddy 登录」顶上，不影响其他功能。

**换电脑了，存档怎么带过去**  
新电脑装好 mod 和云桥，登录同一个账号，在网页「云存档」里点「恢复」即可。

## 实现说明（给好奇的人）

- mod **不直连云端**。云端 SDK 只能在真实浏览器上下文里跑（服务端会校验 Origin），所以由 mod 拉起一个受管的 Edge/Chrome 承载云桥页面。
- mod 和网页之间走本机回环：`http://127.0.0.1:27551`，只在 `127.0.0.1` 上监听，不走公网。
- 浏览器用独立配置目录（`%LOCALAPPDATA%\VPet\cloudbridge_profile`），不会碰你自己日常用的浏览器配置和登录状态。
- 房间与排行榜的读写由网页完成，mod 只是把结果同步到界面里显示。

**日志位置**：`%LOCALAPPDATA%\VPet\cloudbridge.log`
